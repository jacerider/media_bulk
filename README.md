INTRODUCTION
------------

Allows uploading files in bulk and converting them to media entities using the
media library.


REQUIREMENTS
------------

This module requires the media module.


INSTALLATION
------------

Install as you would normally install a contributed Drupal module. Visit
https://www.drupal.org/node/1897420 for further information.
